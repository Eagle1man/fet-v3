сознательно не делалась, чтобы не смешивать фазы.

## Фаза 6. UI-панель (Tkinter) — готово

Реализовано в `src/fetv3/ui/app.py`, запуск: `python -X utf8 run.py ui`.

- Поиск по группе / преподавателю / аудитории / диапазону дат.
- Правка даты, пары, аудитории, преподавателя, предмета.
- Журнал `change_log`: одна транзакция на действие, версия, откат.
- Правки переживают повторный ETL (replay по «период + строка источника»).
- Кнопки пересборки и проверки вызывают CLI, а не дублируют логику.

Осталось по желанию: сетка недели вместо таблицы, подсветка конфликтов,
экспорт выбранной выборки.
