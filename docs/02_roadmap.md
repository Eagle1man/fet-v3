# Что осталось (фазы 6–8 плана)

Ядро переноса готово и проверено. Ниже — работа, которая в этот заход
сознательно не делалась, чтобы не смешивать фазы.

## Фаза 6. UI-панель (Tkinter)

- Поиск по группе / преподавателю / аудитории / дате поверх `schedule.db`.
- Сетка недели, подсветка пар из `out/conflicts`.
- Правка занятия через транзакцию: diff «было → стало», запись в `audit_log`.
- Кнопка «пересобрать и проверить» — вызов `run.py build` + `validate`.
- Требование: правка не должна требовать ручного редактирования `.fet`.

Оценка: 3–4 дня.

## Фаза 7. ИИ-помощник (Ollama, tool-calling)

- Инструменты: `query_lessons`, `edit_lesson`, `generate_fet`, `validate_fet`,
  `export_report`.
- Модель **не пишет XML** и не придумывает данные: только вызовы инструментов,
  результат — из БД и отчётов.
- Проверка: 5 эталонных запросов, журнал вызовов, отсутствие «фантазий».
- Нужна рабочая локальная модель (`ollama list`) и решение по имени модели.

Оценка: 3–4 дня.
