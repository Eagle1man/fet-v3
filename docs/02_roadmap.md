# Что осталось (фазы 6–8 плана)

Ядро переноса готово и проверено. Ниже — работа, которая в этот заход
сознательно не делалась, чтобы не смешивать фазы.

## Фаза 6. UI-панель (Tkinter) — готово

Реализовано в `src/fetv3/ui/app.py`, запуск: `python -X utf8 run.py ui`.

- Поиск по группе / преподавателю / аудитории / диапазону дат.
- Правка даты, пары, аудитории, преподавателя, предмета.
- Журнал `change_log`: одна транзакция на действие, версия, откат.
- Правки переживают повторный ETL (replay по «период + строка источника»).
- Кнопки пересборки и проверки вызывают CLI, а не дублируют логику.

Осталось по желанию: сетка недели вместо таблицы, подсветка конфликтов,
экспорт выбранной выборки.

## Фаза 7. ИИ-помощник (Ollama, tool-calling) — готово

Реализовано в `src/fetv3/ai/`, запуск: `run.py ask "..."` и `run.py chat`.

- Инструменты: `query_lessons`, `edit_lesson` (dry-run + подтверждение),
  `build_fet`, `validate_fet`, `export_report`, `build_status`.
- Модель не генерирует XML и не отвечает по памяти: при ответе без вызова
  инструмента ассистент требует вызвать его.
- `Conversation` хранит историю, поэтому подтверждение правки работает.
- Проверено живьём: `qwen2.5:7b-instruct` корректно вызывает `query_lessons`
  и предлагает перенос пары; `qwen2.5:1.5b` инструменты игнорирует.
- Ошибки Ollama (не запущен, таймаут) возвращаются понятным сообщением.

Осталось по желанию: RAG по документам колледжа (сейчас данные только из БД).
